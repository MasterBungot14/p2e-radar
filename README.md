## 📖 About

**P2E Masters** is a social media aggregator that surfaces the best **Play-to-Earn (P2E)** games from platforms like X (Twitter), Reddit, Discord, and Telegram. Every game listed on the site has been vetted to have a **75%–100% verified earning chance** across both Web2 and Web3.

The site provides a rich, scannable summary of each game including:
- 🎮 **Game Name**
- 💰 **Crypto Token / Currency**
- 📊 **Playable Earning Percentage** (earn rate bar)
- 🌐 **Platform** (Browser / Android)
- ⛓️ **Blockchain** (Web3) or model (Web2)
- 📡 **Social Media Source** (X, Reddit, Discord, Telegram)

## ✨ Features

| Feature | Description |
|---|---|
| 🔍 **Search** | Filter games by name, token, genre, or chain |
| 🏷️ **Filters** | All / Web3 / Web2 / Browser / Android |
| 🔃 **Sorting** | By earn rate, name, or date added |
| 📋 **Game Detail Modal** | Full info popup with animated earn rate bar |
| 📈 **Trending Ticker** | Top 8 games auto-scrolling ticker |
| 📱 **Social Feed** | Live-look social media posts mentioning games |
| 🌌 **Particle Background** | Canvas-based animated particle system |
| ⚡ **Loading Screen** | Branded splash screen on first load |
| ⬆️ **Back to Top** | Floating button appears on scroll |
| 📱 **Fully Responsive** | Mobile, tablet, and desktop |
